# Laravel Performance Lab — CoffeePerf

![Laravel Performance](laravel-performance.png)

**Статус: ⚪ методичка вычитана и проверена запуском (04.10.2026), прохождение впереди.**
**Сложность: базовая.** Проект самостоятельный, кода из других лаб не берёт. Нужен базовый Laravel (маршруты, контроллеры, Eloquent) и Docker Compose на уровне «поднять и посмотреть логи»; k6, профилировщики, OPcache и Octane объясняются с нуля.

## О чём

Измерять, а не гадать. Приложение Coffee Shop с намеренными проблемами (N+1, тяжёлый отчёт без индекса) и миллионом заказов в PostgreSQL; каждое изменение подтверждается цифрами «до / после» при одних и тех же условиях прогона.

## Стек

Laravel 13 (PHP 8.4), PostgreSQL 18, Redis 8, nginx 1.30, k6, Debugbar и Telescope, SPX и Blackfire, OPcache и JIT, Octane + FrankenPHP. Всё в Docker Compose.

## Формат

Методичка [`Perf_Lab_LaravelCoffeePerf.html`](Perf_Lab_LaravelCoffeePerf.html) — открывается в браузере, прогресс по чекбоксам сохраняется локально. Вычитана 04.10.2026 (21 находка, все исправлены): находки — в репозитории [`lab-fixes`](https://github.com/meeymirita/lab-fixes), файл `backend/laravel-performance.md`.

## Что внутри (9 сессий, ~36 ч)

- **Сессия 1** (~4 ч) — стенд, датасет в 1 млн заказов, приложение с проблемами; перцентили, первый замер curl и ApacheBench
- **Сессия 2** (~4 ч) — k6 с нуля: smoke, load, stress, spike, пороги и код возврата; таблица «ДО»
- **Сессия 3** (~3 ч) — Debugbar и Telescope; запрет lazy loading и починка N+1
- **Сессия 4** (~5 ч) — SPX, wall-time против CPU, flamegraph отчёта; Blackfire
- **Сессия 5** (~4 ч) — OPcache и его настройки для продакшна; JIT и честный замер
- **Сессия 6** (~5 ч) — `optimize` и `route:cache`, кеш с тегами в Redis, cache stampede и блокировки, индексы и `EXPLAIN`
- **Сессия 7** (~4 ч) — Octane на FrankenPHP, сравнение с PHP-FPM на k6
- **Сессия 8** (~4 ч) — подводные камни Octane: чужие данные между пользователями, утечки памяти
- **Сессия 9** (~3 ч) — таблица «до → после», бюджет p95 и регрессионный тест k6 в CI, prod-образ

Разделы 1–10 методички — теория и план, 11–14 — чек-лист «концепция ↔ где в коде», глоссарий, вопросы для собеседования, что дальше.
